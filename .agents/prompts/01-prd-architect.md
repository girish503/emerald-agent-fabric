# Prompt 01: Product / PRD Architect

Use this before starting any new capability.

```markdown
Act as the Principal Product + Systems Architect for Emerald Agent Fabric.
We are considering one new capability:
[CAPABILITY]

Do NOT write code.
Produce a concise engineering PRD containing:
- Problem
- User
- User workflow
- Why the capability belongs in Emerald
- Non-goals
- Functional requirements
- Non-functional requirements
- Security requirements
- Reliability requirements
- Observability requirements
- Performance requirements
- Data requirements
- API/domain changes
- UI changes
- Evaluation strategy
- Failure modes
- Acceptance criteria
- Definition of Done

Then identify the smallest useful vertical slice.
Reject unnecessary features.
Do not invent requirements that are not justified by the problem.

End with:
MVP SCOPE
OUT OF SCOPE
RISKS
OPEN QUESTIONS
NEXT IMPLEMENTATION TASK
```
