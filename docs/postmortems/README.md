# Postmortems Directory

This directory stores blameless engineering postmortems for unexpected failures, regressions, security incidents, or broken invariants in the Emerald Agent Fabric.

## Postmortem Format
- **Date**: YYYY-MM-DD
- **Incident Summary**: Brief description of the failure.
- **Impact**: Affected runs, benchmark accuracy, or security exposure.
- **Root Cause**: Deep technical analysis of the defect.
- **Timeline**: Exact chronological sequence of events.
- **Resolution**: How the immediate issue was remediated.
- **Preventative Actions**: Concrete architectural, test, or policy changes to permanently prevent recurrence.
