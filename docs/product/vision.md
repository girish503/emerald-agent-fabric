# Emerald Agent Fabric: Product Vision

## 1. Executive Summary
Emerald Agent Fabric is an experimental infrastructure system for safely executing autonomous software-engineering agents.

Rather than being another application that attempts to write code automatically from a user prompt, Emerald Agent Fabric is an experimental infrastructure layer for studying how autonomous AI agents should reason, act, recover, secure themselves, and improve when operating on real software systems.

## 2. The Central Research Question
> Can an AI agent operate on real software systems while remaining observable, bounded, recoverable, verifiable, and progressively more efficient?

## 3. What Emerald Is and Is Not

### Emerald IS:
- A research-grade agent execution runtime.
- A capability-secured environment with sandboxed execution.
- An adaptive reasoning and reflex framework.
- An observable, typed tool orchestration fabric.
- A verifiable evidence generation and deterministic replay engine.
- An evolving harness evaluation laboratory.

### Emerald is NOT:
- A ChatGPT clone.
- A generic coding assistant.
- A Devin or OpenHands clone.
- A model-training project.
- A prompt wrapper.
- A collection of unrelated AI features.

## 4. Architectural Pillars
1. **Correctness over Complexity**: Smallest working vertical slice; no speculative architecture.
2. **Evidence over Claims**: Deterministic evaluation over subjective "looks good".
3. **Defense in Depth**: Model -> Tool -> Policy -> Capability -> Sandbox -> Network -> Human approval.
4. **Model Independence**: Pluggable provider adapters (OpenAI, Anthropic, Gemini, Local).
5. **CPU-First**: Runs effectively on standard developer workstations without requiring massive cloud infrastructure prematurely.
