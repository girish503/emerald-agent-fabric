# Emerald Agent Fabric: Research Questions

## Primary Research Question
Can an AI agent operate on real software systems while remaining observable, bounded, recoverable, verifiable, and progressively more efficient?

## Secondary Questions
1. **Adaptive Reflex vs Static Prompting**: Does a lightweight, observable Reflex decision layer reduce total latency and token cost compared to asking a frontier model to plan all checks upfront?
2. **Deterministic Replay Fidelity**: What is the minimal state capture required to guarantee 100% reproducible execution of agent runs across environments?
3. **Capability Boundary Tightening**: What is the minimal set of OS capabilities and tool primitives required for software engineering agents to solve complex SWE-bench issues without exposing the host?
4. **Harness Evolution Dynamics**: Can prompt and tool harness changes be evolved and promoted monotonically using strict benchmark suites without regression?
